Notes that stay plain files.

Larkfold is a desktop notebook. Write in Markdown and keep everything in one folder you choose.

Get Larkfold What it does

Windows 10 or later, 64-bit.

What it does

Plain files

Every note is a Markdown file in your folder. Open it in any editor.

Works offline

No account and no sign-in. Larkfold runs without a network connection.

Fast search

Search covers every note and updates as you type.

Exports

Export a note or a whole folder to PDF, HTML or plain text.
