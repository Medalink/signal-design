sd-item-row = a box around the sd-item link and an sd-item-actions cell, as siblings, because a link cannot hold a button · the box carries hover, keyboard focus and aria-current (set on the link) for both · the cell shows on hover and keyboard focus, always on touch (hover: none), and Tab reaches the link, then the action · the cell keeps its width on every row, empty when a row has nothing to do (the read row above), so the time column holds and long text ends before the button
