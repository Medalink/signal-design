Signal design

Signal. Flat, square, mono.

A design library for Tailwind v4 apps, plain HTML and Tauri. Two faces, two weights, square corners, flat greys, and color only where it means something.

  • Tailwind 4.3
  • No dependencies
  • WebView2 · WebKit · Chromium

01

Tokens

Raw values live in @theme and become utilities. Semantic roles switch per theme at runtime, so bg-canvas or text-fg-muted follow the theme with no rebuild. Values below are read live from the current theme.

Hard rules

  1. Square corners everywhere, avatars and checkboxes included.
  2. Flat surfaces. No glass, grain, glow or shadow. Fades are for borders and edges only.
  3. Color is for important things: risk, status, success, focus. Everything else is black, white and grey, navigation included.
  4. Motion on state change only: 120–200ms transitions and a one-pass hover shimmer. The rain moves only while work runs.
  5. Minimal by default, detail on expand.
  6. SF Pro for text in regular and medium; Source Code Pro for code. The font picker swaps the text face.

Semantic roles

Signals

The only saturated colors. Each one has a job. Use the role (text-danger), not the hue (text-pink), so paper (the light theme) can deepen it.

Greys

Ink is the shipped Signal ramp: cool and near-black. Graphite is the original ramp from the spec table. The ink theme uses the first, the graphite theme the second.

Spec vs shipped

The original spec table and the shipped stylesheet disagree. Ink, the shipped ramp, is the canonical default. Graphite keeps the spec values as an optional theme.

AttributeDoes
data-sd-open="id" · data-sd-closeOpens a dialog as modal; closes the nearest dialog. Backdrop click closes unless data-sd-static.
popovertarget + .sd-popoverPlaces the popover next to its trigger, flips at edges, keyboard for menus.
role="tab"Selects tabs and panels, arrow keys, roving focus.
data-sd-toggle="id"Opens and closes an .sd-expand, keeps aria-expanded in sync.
data-sd-segSingle-select button group; fires change.
data-sd-key="a"Clicks the element when the key is pressed (ignored while typing).
data-sd-tip="text"Tooltip on hover and focus.
data-sd-copy="#id"Copies text, or explains that copying is unavailable.
data-sd-toast="text"Shows a toast on click.
data-sd-theme="paper"Switches theme and remembers it.
