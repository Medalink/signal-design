Optional and dependency-free. It reads data-sd-* attributes and writes ARIA and data-* state. The CSS styles that state.

Optional, under 5 KB gzipped, no dependencies. Every listener is delegated, so markup added later just works. It sets ARIA and data-* state; the CSS styles that state.

Principles

  • Delegated listeners. Every listener is delegated, so markup added later works without calling init() again.
  • State is attributes, never classes. Your Tailwind build never needs to contain a class the JS adds, and tests or app code can set the same attributes.
  • One writer per state. If a framework renders a piece's state, leave out its data-sd-* behavior attribute. The Framework-owned state block shows how.
  • Heavy parts mount explicitly. Living tables, countdowns and feeds use mountLivingTable, mountCountdown and mountFeed. init() does not mount them.
  • Typing is never hijacked. data-sd-key and hotkeys ignore keys typed into a field, except Ctrl or Cmd combinations.

Use it for

  • Dialogs, popovers, tabs, toggles, tooltips and copy buttons from attributes alone.
  • Live lists that must keep the reader's place: mountFeed.
  • Theme switching: setTheme, data-sd-theme and Shift T.

Leave it out when

  • Loading it where the HTML works with CSS alone. Each block says whether it needs JS.
  • Driving a piece's state from both init() and a framework.
  • Reading classes the JS never adds. Read ARIA and data-* instead.

Setup and attributes

main.js 
import { init, toast, hotkeys, setTheme } from "signal-design/js";

init();                                   // dialogs, popovers, menus, tabs, tooltips, toggles
toast("Saved", { tone: "success" });
const off = hotkeys({ j: next, k: prev, "shift+n": newest, "mod+k": search });
setTheme("paper");                        // ink | graphite | paper | auto
AttributeDoes
data-sd-open="id" · data-sd-closeOpens a dialog as modal; closes the nearest dialog. Backdrop click closes unless data-sd-static.
popovertarget + .sd-popoverPlaces the popover next to its trigger, flips at edges, keyboard for menus.
role="tab"Selects tabs and panels, arrow keys, roving focus.
data-sd-toggle="id"Opens and closes an .sd-expand, keeps aria-expanded in sync.
data-sd-segSingle-select button group; fires change.
data-sd-key="a"Clicks the element when the key is pressed (ignored while typing).
data-sd-tip="text"Tooltip on hover and focus.
data-sd-copy="#id"Copies text, or explains that copying is unavailable.
data-sd-toast="text"Shows a toast on click.
data-sd-theme="paper"Switches theme and remembers it.
Try:

init() once after the DOM exists; listeners are delegated, so later markup works · toast(text, { tone }) · hotkeys({ key: fn }) returns the off function · setTheme("ink|graphite|paper|auto") · every data-sd-* attribute does nothing without init() · a framework that renders the state leaves the attribute out and sets ARIA and data-* itself

Copy feedback

Copy needs browser clipboard access. On an insecure LAN connection, or when permission is denied, the danger toast says "Copy unavailable. Select the line instead." The command stays selectable. Successful copies still say "Copied". No insecure clipboard bypass is used.
