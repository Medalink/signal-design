Two ways to chart, both on the --sd-chart-* tokens. sd-plot and the square charts are CSS only. createChart adds time axes, units, bands and live data on Chart.js.

Time series, generic chart types and square charts, all on the --sd-chart-* tokens. Switch mono and spectrum from the settings button in the bar above. Live charts need Chart.js; square charts and sd-plot are CSS only.

Principles

  • Mono by default. Series are greys until data-chart-theme is spectrum. Switch it from the settings button in the bar above.
  • Square marks. Heatmaps, waffles and uptime strips are squares. Nothing glows or fades into a gradient.
  • One palette everywhere. A sparkline in a table matches the full chart above it, because both follow data-chart-theme on the element or any element above it.
  • Scales stay honest. A scale mode (clamp, p95, p90, linear or log) keeps one spike from flattening the rest, and the choice is remembered.
  • Load Chart.js only where you chart. It is an optional peer dependency. This is the only library page that loads it.

Use it for

  • A handful of points with no axes: sd-plot.
  • Bandwidth, latency and other series over time: createChart, with live appends.
  • Counts of states over a grid: heatmaps, waffles and uptime strips.

Leave it out when

  • Spectrum colors for anything but data. Navigation, headings and icons stay grey.
  • Loading Chart.js for a sparkline. sd-spark and sd-plot need no library.
  • Reading a value from color alone. Tooltips and legends carry the numbers.

Gallery

The same tokens drive every chart type: createChart(canvas, { type }) for line, area, step, bar, ranking bars, histogram and scatter, and CSS-only squares for heatmaps, part-of-whole, uptime and meters. Series take colors 1–6 in order; in mono, lines also take a dash each.

Plots from your own points

When your app already has the points and wants a small, static line, draw an SVG and let sd-plot style it. No Chart.js, no axes, no live engine. data-series picks the same color as the matching chart series.
