Parts for what plain elements cannot do: buttons, fields, rows, navigation, feedback and overlays. Tone and state come from attributes, so your CSS, your code and a screen reader agree on what is true.

Classes start with sd-. Color comes from data-tone: accent, success, danger, warning, pending, extra, neutral. State comes from ARIA and data-*, so the JS never needs your Tailwind build to contain a class.

Principles

  • Tone is data. data-tone takes accent, success, danger, warning, pending, extra or neutral. A part never takes a color class.
  • State is ARIA. aria-pressed, aria-expanded, aria-current and aria-selected drive the styling. Set them from your own code and the part follows.
  • One writer per state. Where React, Vue or Svelte renders a piece's state, leave out its data-sd-* behavior attribute and render the attributes yourself. The Framework state page has an example.
  • Minimal by default. A row shows its outcome and expands for detail. A view has one primary button.
  • Square, flat, grey. Parts use hairline borders and no shadows. Navigation stays grey, and color marks status.

Use it for

  • Status with sd-badge, sd-status, sd-dot and sd-count, each of which takes a tone.
  • Lists of work: rows, tables, key-value lists and living tables.
  • Overlays: dialogs, sheets, popovers, menus and tooltips, wired by init().

Leave it out when

  • Coloring navigation, headings or icons. Color is for status.
  • A looping progress bar. When the amount is unknown, set data-state="indeterminate" on sd-progress. It stays still.
  • Your own sidebar layout around an app. Use the App Shell, sd-shell.

Hard rules

  1. Square corners everywhere, avatars and checkboxes included.
  2. Flat surfaces. No glass, grain, glow or shadow. Fades are for borders and edges only.
  3. Color is for important things: risk, status, success, focus. Everything else is black, white and grey, navigation included.
  4. Motion on state change only: 120–200ms transitions and a one-pass hover shimmer. The rain moves only while work runs or when the reader turns it on.
  5. Minimal by default, detail on expand.
  6. SF Pro for text in regular and medium; Source Code Pro for code. The font picker swaps the text face.
