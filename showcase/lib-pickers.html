Controls for choosing, filtering and finding: combobox, tags, number steppers, steps, a command palette and a shortcut sheet. Small sparklines, bars and diffs need no library.

The form example uses these together.

Principles

  • Real inputs underneath. The combobox keeps a text input and a hidden input for the value. Tags keep a hidden input per tag. Forms submit as they always did.
  • Every action has a key. Arrows move, Enter chooses, Esc closes, Backspace removes the last tag, and ? opens the shortcut sheet.
  • Shortcuts stay out of text fields. data-sd-key does not fire while you type, except combinations with Ctrl or Cmd such as Ctrl K.
  • One key, one owner. data-sd-key clicks the first visible match. Give Ctrl K to one palette per page.
  • Small data needs no library. sd-spark reads data-values and sd-bars reads --v. Both are static.

Use it for

  • Forms with search, tags or numeric steps.
  • A command palette for jumping to pages and running actions.
  • A shortcut sheet, so keyboard users can find what exists.

Leave it out when

  • Time axes, units or live data. Use the Charts page: createChart with Chart.js.
  • A second palette on a page that already has one on Ctrl K.
  • A short list of options. A native <select> or radio group is simpler.
