Framework-owned state

When React, Vue or Svelte renders a piece's state, leave out its data-sd-* attribute and render the ARIA and data-* attributes the CSS keys on. These three have no data-sd-*: this page's own code keeps the state and writes the attributes, as a framework would. README "Framework-owned state" lists every piece and what init() wires without an attribute (role="tab", .sd-shell, popovers, scrollers).
